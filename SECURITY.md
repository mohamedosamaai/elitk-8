# Security Policy

## Reporting

This is a private repository. Report security issues directly to @mohamedosamaai.

Do not open public issues or pull requests that include secrets, credentials, access tokens, private keys, customer data, or exploitable implementation details.

## Secrets

- Never commit `.env` files, service account keys, API tokens, or production credentials.
- Rotate any exposed credential immediately.
- Keep deployment and infrastructure changes explicit in pull requests.

## Supported Branches

Security fixes should target the repository default branch unless Mohamed Osama instructs otherwise.
